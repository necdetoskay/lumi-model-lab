# SERA v0.21 — Source-Bound Model Writer and Recheck Integration

**Experimental:** v0.21 connects the real SERA OpenRouter transport and actual
v0.19/v0.20 scene validators to the v0.20 unattended rewrite interface. This
does not authorize canon commits or turn the existing LUMI story worker into a
complete autonomous pipeline. All included regression tests are zero-billable.

## 1. Generalized world aspect roles

The v0.13 pure typed-facet reducer and v0.20 recovery no longer demand
both a document and an openable object in the same scene. A source with
only one facet family works, without phantom entities or a Mara-specific
object/name list. The empty typed registry still fails closed.

## 2. Real provider-to-writer adapter

[openrouter_scene_writer_v021.py](./openrouter_scene_writer_v021.py)
reuses the existing SERA OpenRouter request path (the v0.5 provider
transport). The request carries exact original prose, immutable
story context, verified defect candidates and original source SHA-256.
It has **no application-configured output-token ceiling**.

The adapter does not create a model call on import/construction; its
writer callback performs the requested call once automatically, and
requires the actual provider reply's model, ID, usage cost and
completion reason. Model-emitted "approval" or fabricated provider
receipts are not accepted. It supports a single complete JSON object
or a strictly complete JSON code fence, not arbitrary prose.

For a durable paid workflow, set **archive_dir**: the response is
written to disk with the originating request+model SHA **before**
model JSON validation. If the first fully receipted response is malformed,
a separately configured alternative model is invoked **automatically**,
without showing the original model's assessment as ground truth.
All paid attempt costs are summed; each individual raw reply is archived.
Re-entering the same request reuses the archived responses without another
billable call. Unknown in-flight/unreceipted responses are never blindly
resent. There is an observed USD spend guard and at most one fallback;
these are NOT output token ceilings.

A future production adapter must also implement provider-side request
idempotency/reconciliation after a response was charged but lost before
the disk archive; safe terminal failure is used until then.

## 3. Actual archived-evidence validator

[artifact_scene_checker_v021.py](./artifact_scene_checker_v021.py)
reads a hashed and version-bound offline evidence bundle for **each exact
draft**. It runs the actual
[event_candidate_projection_v019.py](./event_candidate_projection_v019.py)
and [typed_aspect_recovery_v020.py](./typed_aspect_recovery_v020.py) code
instead of returning a fabricated READY decision. The model's semantic
output is re-bound to original source evidence; object roles, source order,
CAS, state history and unchanged canonical world are validated.

**Important gap:** the evidence bundle for each newly rewritten draft is
not yet automatically regenerated by the real durable extraction worker.
If an archive for a fresh prose SHA is missing, the recheck fails closed
instead of copying previous conclusions or falsely declaring a completed
scene. This is the NEXT critical connection. The new archive checker is
nonbillable; actual new extraction is billable and must be separately
receipted/recoverable by its worker. It must not occur inside a supposedly
nonbillable callback.

## 4. Durable scene loop correction

The v0.20 controller now safely repeats an interrupted **nonbillable**
source validator after a crash, with unchanged source fingerprint. A paid
writer call still cannot be blindly repeated after an unknown in-flight
provider outcome. All available checkpoints are replayed without manual
intervention.

## Proof and remaining release gates

Offline regression tests exercise a full v0.20 rewrite loop with the
real OpenRouter-shaped writer adapter and synthetic zero-cost provider,
raw archived-paid-response replay and automatic fallback, total cost
accounting, source/role changes, actual v0.19+v0.20 checks, missing-new-
draft-evidence HOLD, and browser E2E.

**NOT YET IMPLEMENTED:** automatic paid source re-extraction/semantic
requalification for each new draft; production story worker binding;
real provider idempotent reconciliation; authenticated machine-only
WorldState/EventGraph commit+rollback; complete first Mara S1 and unseen
story end-to-end qualification.

No production database writes, no paid calls during v0.21 tests,
no manual corrections/approvals, and no app-generated model output caps.
Original Sonnet Spine remains unchanged. Mara S1 is still HOLD.
