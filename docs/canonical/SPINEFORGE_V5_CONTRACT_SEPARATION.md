# SpineForge v5 — Creative Seed / Structural Compiler Separation

Status: IMPLEMENTATION CANDIDATE — ZERO-COST ONLY

## Why v5 exists

SpineForge v4 completed three explicitly authorized paid attempts and failed qualification without reaching Sonnet.

The failure sequence was:
1. Attempt 1 — Aion emitted a scalar where the final EpisodeSpine contract required a list.
2. Attempt 2 — revision feedback fixed that defect, but Aion omitted mandatory COMPLICATION.
3. Attempt 3 — revision feedback fixed COMPLICATION, but one beat omitted required new_information.

The creative story core remained strong and each feedback package corrected the immediately preceding defect. The repeated failure class was contract authorship reliability: Aion 3.5 Mini is a storytelling/roleplay model exposed through json_object formatting, not provider-enforced strict JSON Schema.

v5 does not patch v4. v4 remains immutable failed evidence.

## Ownership correction

v4 asked Aion to be both creative architect and author of the entire strict EpisodeSpine application contract.

v5 separates those responsibilities.

Pipeline:

→ application-owned Structural Obligations
→ Aion Creative Seed Architect
→ CreativeSpineSeedV5
→ Sonnet Structural Compiler + Hardener
→ strict EpisodeSpineV3

Writer remains unreachable from SpineForge.

## Aion boundary

Aion owns dramatic engine, desire and pressure, wonder/intrigue, memorable scene intents, protagonist actions, discoveries/changes, decision pressure/options, climax intent, local payoff, forward hook, and creative texture.

Aion does NOT author final EpisodeSpine phase topology, final per-beat validator bookkeeping, application-owned age/session/word targets, Saga milestone authority, or provider/model lineage.

This removes the three observed v4 failure classes from the Aion boundary.

## Application-owned structural obligations

The application deterministically supplies:
- mandatory phases HOOK, COMPLICATION, REVERSAL, DECISION, CLIMAX, PAYOFF;
- beat count 8–12;
- exact required beat fields;
- causal dependency rule;
- reversal evidence boundary;
- minimum two decision branches;
- canonical premise key;
- exact age;
- session;
- word targets;
- intended milestone keys.

The obligations contain no scenario-specific recovery code and no hidden Saga truth.

## Sonnet boundary

Sonnet receives the same immutable ContextPack, Aion's seed, and the structural obligations.

Sonnet compiles and hardens the seed into the strict EpisodeSpine. It may return REPLAN instead of silently violating creative or canonical authority.

## Luna boundary

Luna evaluates the compiled product. ACCEPT still leads only to AWAITING_HUMAN_REVIEW.

Human approval remains mandatory before Writer authorization.
