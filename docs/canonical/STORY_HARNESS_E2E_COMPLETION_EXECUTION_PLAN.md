# LUMI Model Lab — Story Harness End-to-End Completion and Acceptance Plan

**Plan created:** 2026-10-13 · **Starting state:** P4.14, Draft [PR #275](https://github.com/necdetoskay/lumi-model-lab/pull/275), open [quality #291](https://github.com/necdetoskay/lumi-model-lab/issues/291), commit `7faa8cbe0d539c09428fba9f5b6a25e2807c7c43`, CI [#38399563077](https://github.com/necdetoskay/lumi-model-lab/actions/runs/38399563077) GREEN. This file is an **execution plan**; writing it is not implementing its remaining steps, authorizing spend, or declaring story quality acceptance.

## North star and non-negotiables

Build a reproducible, **model-generated** story from immutable LUMI Canon/Spine, then give that same story (identified by artifact ID + exact SHA) to the independent quality gate, seal only a genuinely accepted English Master, run genuine same-story Q25/State extraction, and produce evidence-bound Final StoryState without inventing unknown facts. One edited candidate accepted is NOT proof that future input-to-story generation works.

Keep the original frozen v21.4 and baseline approvals/hashes unchanged. No automatic model retries, <=3 quality calls, <=1 scene repair, no full-story final re-audit, no fallback model/provider, fail closed on missing cost/token usage, source mismatch, transport ambiguity, out-of-scope serious finding, unexpected charge, or any authorization lapse. Only a human-approved explicitly versioned change may alter a frozen policy; never silently lower the quality bar or enlarge the repair envelope. Production LUMI remains untouched until a separate production decision after Model Lab qualification.

## B — First genuine SAME-STORY acceptance

### B1. One authorized real bounded v21 quality attempt (P5.0)

**Cost:** only after explicit finite operator approval; not included in current plan creation.

Use unchanged 2,491-word **editorially revised Writer candidate** for the pilot. Original frozen approved Spine SHA and actual story SHA are mandatory. The real original v21 quality runtime invokes:

1. `INITIAL_AUDIT` (one real Sonnet 5.5 call). Validate serious/critical findings by original contract.
2. If no blockers, use the original engine's clean accepted path. If serious findings are exclusively repairable within approved S167–S203 and invariant constraints, invoke **exactly ONE** `SCENE_REPAIR`. If outside scope, structural, temporal/causal/canon or otherwise unrepairable under one cluster: **REJECT**.
3. After a repair only, perform **targeted FINAL_AUDIT for repaired scene + boundaries**, never a full-manuscript re-audit. Unexpected new/outside defects: `REJECT_NON_CONVERGENT`. No second repair.
4. Immutable archive every stage's exact input/output, real tokens/charge/latency, boundaries, provider generation identity, accepted/rejected verdict and remaining budget. Unknown cost or provider failure: STOP, no retry.
5. Never claim `ACCEPT` from any fake provider responses or manual assistant editorial judgments.

**Exit:** genuinely independently model-audited `ACCEPT` **or** explicit trustworthy `REJECT` with evidence. A REJECT is honest test evidence, not a reason to bypass the gate.

### B2. English Master admission (P5.1)

**Trigger only if B1 = genuine ACCEPT.** Atomically seal accepted English text SHA, source Writer and approved Spine/context lineage, quality result SHA, claim/usage ledger, and final immutable Master artifact. Deny old story, differing hashes, provisional/mock verdicts, invalid cost/authorization. No production writing.

**Exit:** one real English Master with unbroken lineage; no admission if rejected.

### B3. Q25 → Final StoryState, SAME story (P5.2)

1. Run original genuine Q25 validator on that **exact English Master** (not an older/different Q25 passing story). Verify input provenance, immutable SHA and recorded segment lineage.
2. Extract final characters/locations/inventory/object ownership, current goals, completed obligations and epistemic facts from *the English Master text*, each grounded in explicit passages; unknown facts remain unknown, no invented owner/location. Reconcile with original Canon and World rules.
3. Generate a read-only Final StoryState candidate; check evidence anchors, temporal/causal transitions and no contradictory state claims. Reject unsupported mutations and never commit production state.
4. Persist full immutable chain: `Canon → SpineForge → Writer → real Q Gate → English Master → Q25 → Final StoryState candidate`.

**Exit:** verifiable full same-story immutable chain with a defensible terminal state. State creation does not authorize production commit.

### B4. Reader quality and optional TR output (P5.3)

Evaluate narrative interest, 12-year-old age fit, coherent roleplay, agency/character response, sentence flow, spine fidelity and ending closure under an explicit rubric and human review; do not infer literary excellence merely from technical validator PASS. If translation is needed, derive TR separately from frozen English Master, validate identity, event/state fidelity, and never let translated details mutate English Canon. English/Q25 truth remains authoritative.

**Exit:** first story technical/semantic and reader evaluation published, with clear editorial caveats.

**Exit:** published performance/cost/quality comparison and clearly specified admission threshold for a production candidate.

## Execution loop, expected evidence and ownership

For each engineering slice: `inspect HEAD → implement minimal code → add negative tests → local/tests available → GitHub CI → fix any red test → repeat until GREEN → append exact commit/run/test counts to #291 and PR`. Never merge a Draft or deploy production just because CI is GREEN. Manual stops require **only genuine missing decisions or privileged provider operations**, not repeated prompts for facts already available.

**Two separate success definitions:**

**Pilot acceptance:** one actual immutable editor-revised story that independently passes v21 and reaches evidence-linked Final StoryState candidate.

**Full LUMI story-line acceptance:** at least three new autonomous model-generated stories all flowing end to end with accountable costs, original source truth and reader evaluation. Passing the first definition does not assert the second.

**Cost boundary:** all planned code/repository/CI work remains free of paid provider inference; the exact live budget (candidate $0.25 for quality alone) is a future separate operator decision. It is NOT budget approval for model-generated Writer, translation, Q25 if provider-billed, further stories, reruns, or production deployments.
