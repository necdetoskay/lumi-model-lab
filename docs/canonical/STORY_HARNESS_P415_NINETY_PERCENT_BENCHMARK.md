# Story Harness P4.15 — State+topic success metric and controlled fix loop

**13 October 2026** · Draft [PR #275](https://github.com/necdetoskay/lumi-model-lab/pull/275) · Issue [#291](https://github.com/necdetoskay/lumi-model-lab/issues/291)

## User goal is now explicit

**At least 90% SUCCESS from arbitrary valid state + topic, producing a complete, age-appropriate and engaging story through the entire same-story immutable chain without manual prose editing.** Input state, prompt/genre and age are runtime parameters, NOT the frozen P4.8 2,491-word 12-year-old editorial candidate. The latter proves only an isolated quality-gate pilot and must never be counted as a fully autonomously created story.

The owner authorized an **aggregate US$10 new paid model inference budget** for controlled attempts, not a waiver of safe account/key provisioning, independent cost receipt or the frozen v21 lower per-stage caps. There are no keys available to the current SentinelX runner shell and no dedicated OpenRouter spend-limited key authenticated in this phase; this work generates **no paid inference**. The user permits public web research if debugging requires outside insight.

## Truthful 90% outcome measure

`configs/story_harness_p415_benchmark.json` defines 10 distinct pilot inputs (2 each at ages 4, 10, 12, 25, 40) with different genres/topics, immutable synthetic world states, unknown canon facts and specific non-invention constraints. The cases are *synthetic input coverage*, not production state or model-generated fiction. Their required checks are:

1. Writer text genuinely generated by a model from the case's exact Canon state, topic and approved Spine, no manual prose patches.
2. Strict fidelity to state/spine/cause/physics/knowledge, age, time and active story obligations.
3. **Independent genuine model quality ACCEPT**, not a simulated green callback; serious blocking defects = 0 and only bounded one-scene repair.
4. Genuine English Master text identity/lineage and same-story **Q25** pass.
5. Evidence-based, non-invented Final StoryState candidate with invariant preservation.
6. Reader score >= 4/5 for story interest, roleplay, age appropriateness, coherent agency and ending closure, from independently recorded external review.
7. Source identity, immutable hashes, verified real provider spend; completed without human intervention.

A **single successful story** must pass every applicable check. Pilot threshold is **9/10**; release holdout threshold is at least **27/30 NEW unseen independently selected inputs**, ideally more samples and explicit confidence intervals before claiming generalization. Ten of ten fixtures alone cannot support 90% statistical reliability across arbitrary future user inputs; the reported rate is sample-specific. CI and synthetic verifier metadata can NEVER satisfy the real-acceptance gate.

`src/story_harness_p415_benchmark.py` only validates coverage, quantifies required thresholds, validates input SHAs and claimed cost, and **explicitly refuses real 90% achievement even if handed 10 forged ACCEPT receipts**. A separate real artifact-linked verified runner and independent reviewer is required to replace unverified claims with admitted genuine results. No quality model call is made.

## User-requested 3-fix loop

For EACH independently classified failure family:

`Reproduce → root-cause hypothesis → minimal fix of SAME approach → targeted regression offline GREEN → CI GREEN → (only if separately budgeted and safe) new model run`.

- Each fix must be materially distinct, traceable to commit SHA, with a green deterministic regression. Record outcome/failure family in issue #291.
- If still failing, do fix 2, then fix 3. **Do not switch strategies after failure 1 without first attempting fixes 2 and 3** unless current method is shown unsafe/impossible (e.g. secrets missing, frozen hard limits contradictory).
- After three independently tested *failed* corrections, STOP and write a brief alternative method + reason for review. Never unlimited model retries, same invoice re-use or false provider ACCEPT.
- A successful correction is verified, not repeated two more times merely to hit three.
- Provider transport timeout, unknown charge or malformed response **consumes the attempt and stops**. A later retest uses a separately permitted new run under the remaining US$10 budget. No retries inside a quality run, max 3 quality calls / 1 scene repair as originally specified.

## Current engineering work, not yet achieved

P4.15 is a measurable benchmark and corrective-action protocol. Existing P4.8–P4.14 code is hardcoded to one editorial story, one age, one fixed 37-span bridge scene and one model. Thus **the claim of a state/topic-generalized 90% success system would be false today**. Next engineering priority is input-driven state/topic → Spine/Writer contract, followed by a REAL cost-isolated end-to-end smoke run, not additional abstract security wrappers. Use the frozen originals as sources of validity, rather than quietly editing them.

**No public benchmark fixtures are blind**: holdout 30+ must be generated/sealed independently and not tuned on during development. Strongest release claim requires both demonstrated sample rate and full provider/reader audit trace; never infer 90% from CI.
