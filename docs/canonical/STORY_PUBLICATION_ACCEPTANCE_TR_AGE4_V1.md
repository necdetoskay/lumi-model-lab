# LUMI Story Publication Acceptance Contract — TR Exact Age 4 v1

Status: CANONICAL / FROZEN

This contract defines the production publication gate for Turkish stories targeting exact age 4.
Individual judge runs, benchmark-editor preferences, or one-off story critiques MUST NOT mutate this contract.
Changes require explicit regression evidence and a versioned contract revision.

## 1. Product target

A story passes when it is understandable and coherent for an exact-age-4 listener, natural Turkish for adult read-aloud, canon-consistent, physically/logically coherent, free of publication-blocking adult/teacher leakage, and inside the hard word-count range.

The target is publishable, not “an editor can no longer suggest any stylistic change.”

## 2. Hard fail classes

A story is publication_ready=false if any of the following is present at critical or serious severity:

1. canon_violation — invented/contradictory canon-relevant identity, relationship, world fact, or StoryContract fact.
2. logic_or_physical_break — materially impossible, contradictory, or incomprehensible action/continuity.
3. broken_turkish — clearly broken, unnatural, or translation-like Turkish that harms comprehension/read-aloud.
4. age_mismatch — clearly adult/analytical reasoning, vocabulary, or abstraction attributed to the age-4 child.
5. caregiver_teacher — caregiver materially turns the scene into correction, examination, lesson, or answer-leading instruction instead of natural participation.
6. story_structure_break — unresolved/broken story arc, missing payoff, severe loop/repetition, or a scene sequence that no longer coheres.
7. visible_generation_artifact — obvious checklist, benchmark, system-prompt, AI/meta, or safety-boilerplate leakage.
8. hard_length_failure — final story is outside 375–625 words for this profile.

## 3. Non-blocking quality observations

The following may be recorded but MUST NOT by themselves fail publication:
- a sentence that could be prettier or shorter,
- minor rhythm/read-aloud preference,
- harmless visible gesture,
- playful child logic,
- small literary/register preference that remains age-comprehensible,
- optional stronger joke/warmth/ending suggestion,
- minor repetition that does not impair reading,
- editor preference for another wording.

Moderate and minor observations are evidence/backlog material, not automatic regeneration triggers.

## 4. Repair budget

Production repair is bounded:
1. Generate draft.
2. Run one local edit pass for concrete findings.
3. Run one independent final acceptance check.
4. Stop.

There is no recursive judge → repair → judge → repair loop in the production acceptance path.
If the single final acceptance check still reports a critical or serious hard-fail class, the story fails the attempt. It may be regenerated by the caller as a new attempt, but the same artifact is not repeatedly rewritten.

## 5. Judge authority

The final judge answers only the frozen acceptance contract.
It is NOT asked to find more improvements, maximize criticism, or provide a fixed number of changes.
The judge may return zero defects.

External editorial benchmarks remain useful for research and model comparison, but do not override the production publication gate.

## 6. Length

For tr / exact_age=4 / target≈500:
- hard minimum: 375 words
- hard maximum: 625 words
- preferred generation target: 475–525 words

No provider token cap is introduced by this contract.

## 7. Change control

A new acceptance rule requires repeated evidence across more than one story family, or a single unambiguous blocker; regression against frozen examples; and an explicit contract version bump.
One judge run or one stylistic complaint is never enough to modify this contract.
