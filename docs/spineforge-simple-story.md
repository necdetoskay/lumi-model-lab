# Whole-story comparison lane

This separate experiment preserves the historical scene engine and all closed qualification records. It does not change production LUMI.

The immutable request and initial state go through:

1. Aion 3.5 Mini proposes three synopses with different conflicts, decisions and resolutions.
2. Sonnet 5.5 selects one and records its reasoning and quality limitations.
3. GPT-5.6 Sol produces a short outline.
4. Aion 3.5 Mini writes the whole story as prose.
5. Sonnet 5.5 extracts persistent final-state changes from that finished prose, with source citations.
6. A separate Sonnet call reviews the prose and extracted state together.

One repair is available. A prose defect goes to Aion and triggers fresh extraction and review. An extraction defect goes to Sonnet without rewriting valid prose. A repeated defect rejects the run. Transport failures and incomplete responses are not retried.

Initial state remains immutable. Acceptance commits a whole-story revision from 0 to 1, records the initial/final comparison and the evidence for each change. This is distinct from the historical six-scene revision sequence. Replay verifies recorded bytes, hashes, calls and admitted transitions; it cannot prove semantic completeness or global originality.

The current admission model preserves the initial entity set, canon, rules and topology. It admits supported changes to existing character/object/world properties, derives spatial positions from entity locations and checks declared container/contents reciprocity. New actors, new topology and arbitrary world-rule changes are outside this experiment's scope. Semantic extraction and review remain fallible; this is not qualification for every possible story request.

All three ideas, the selection, outline, prose attempts, extractions, reviews, raw responses, usage, latency and state comparisons are saved. Synthetic tests are software controls, not real-model quality evidence.

Q24 is prepared using the existing immutable bookmark mystery for comparison with Q22. No paid authorization is created by preparing it. Q23 remains unexecuted; historical permissions are not reopened.

Q24 permits at most nine calls and one repair. No local output-token limit or per-call dollar limit is sent. The proposed USD 1.20 threshold is checked between calls: the completing call may exceed the remaining amount, its full actual charge is recorded, and further calls stop. Missing usage is uncertain cost and fails closed. A fresh paid scope is required before dispatch.
