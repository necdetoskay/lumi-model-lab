Her bölümde olay başlatıcısı, dönüm noktası, karar, bedel ve kapanış özgün Türkçe parafrazla kayıtlıdır. İki soyut mekanik adayına somut kanıt bağlantısı bulunur.

**Önemli:** Bu 40 dosya 250–400 kelimelik tam olay özeti değildir. Kullanıcının NOVA ile işleme talebi doğrultusunda oluşturulmuş olay/karar/mekanizma analizleridir. SG-1 ve Atlantis'in uzun özetlerinden ayrıdır.

**Kaynaklar:** [StargateWiki 40 bölüm rehberi](https://stargate-sg1-solutions.com/wiki/Category:Universe_Episode_Guides) ve GateWorld [1. sezon](https://www.gateworld.net/universe/s1/) / [2. sezon](https://www.gateworld.net/universe/s2/). İlk iki Air parçasının StargateWiki tanıtım özetleri ortaktır; doğru ayrım için GateWorld [Air Part 1](https://www.gateworld.net/universe/s1/air-part-1/) ve [Air Part 2](https://www.gateworld.net/universe/s1/air-part-2/) kullanılmıştır.

40 birincil rehber HTTP 200 olarak okunmuştur. Ham uzun kaynak metni repoya kopyalanmadı; kaynak gövdesi SHA256 özeti NOVA source_manifest dosyasındadır. Olay ayrıntılarının bağımsız ikinci editoryal incelemesi yapılmadı.

**İzolasyon:** LUMI Harness, main, production, prompt veya model değiştirilmedi. Yeni OpenRouter API maliyeti $0.
